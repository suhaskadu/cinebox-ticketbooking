CineBook C++ Data Structures Architecture

Here is how each classical Data Structure is implemented in C++ and powers the CineBook ticket booking system:

2D Array / Matrix (C++ SeatMatrix)

Theater Seating Grid

Represented as a 5-row by 6-column matrix (Seat grid[5][6]). Rows A-E map to index 0-4, columns 1-6 map to index 0-5.

Access Time: O(1) direct row/col indexing
Hash Map (C++ SeatHashMap)

O(1) Instant Seat Lookup

Custom bucket-chaining hash table mapping seat codes (e.g. "C4") directly to seat status, pricing, and lock timestamps.

Lookup & Update: O(1) average time
Min-Heap (C++ LockExpiryPriorityQueue)

5-Minute Temporary Lock Expiry

When a user selects a seat, an expiration tuple (expiry_timestamp, seat_code) is pushed to the min-heap. The earliest expiring lock is always at the root.

Lock Scheduling: O(log N) insertion
FIFO Queue (C++ BookingFIFOQueue)

Booking Transaction Pipeline

Prevents concurrency race conditions when multiple users click confirm simultaneously. Requests are handled First-Come, First-Served in O(1) time.

Enqueue / Dequeue: O(1) time
Doubly Linked List (C++ BookingHistoryDLL)

Booking Audit Trail & Rollback

Maintains chronological history of locks, bookings, and cancellations with bidirectional prev and next pointers for instant rollback.

Append & Rollback: O(1) pointer updates
